# Política de Contestação de Transações e Atendimento a Vítimas de Golpe

> Documento FICTÍCIO criado apenas para a demonstração do LangChain4j. Não reflete políticas reais de nenhuma instituição.

## Contestação de Pix
O cliente que foi vítima de golpe deve abrir a contestação pelo aplicativo, na própria transação, o quanto antes. A instituição aciona o Mecanismo Especial de Devolução (MED) junto à instituição recebedora, seguindo as regras do Banco Central.

## Golpe da falsa central
Nenhum funcionário liga pedindo senha, código recebido por SMS, transferência para "conta segura" ou instalação de aplicativo de acesso remoto. Relatos com esses elementos devem ser classificados como golpe da falsa central.

## Atendimento
- Orientar o cliente a nunca compartilhar senha ou código de verificação.
- Nunca solicitar o número completo do cartão em chat; usar apenas os 4 últimos dígitos.
- Registrar o boletim de ocorrência é recomendado, mas não é condição para abrir a contestação.
